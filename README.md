# TerraForge — Open World RPG (Minimal, Complete)

Deskripsi singkat:
- TerraForge adalah proyek Open World RPG bergaya voxel low-poly.
- Dibangun dengan HTML5, CSS3, JavaScript (ES6) dan Three.js (via CDN).
- Dirancang modular dan siap dikembangkan.

Cara menjalankan:
1. Buka folder proyek di VS Code.
2. Jalankan Live Server extension atau jalankan server sederhana (Contoh: `npx http-server` atau `live-server`).
3. Buka http://127.0.0.1:3000 (atau alamat yang diberikan).

Catatan:
- Tidak memerlukan npm (Three.js dimuat via CDN). Untuk kemudahan pengembangan gunakan Live Server di VSCode.
- Save game memakai localStorage.

Struktur:
- index.html
- css/ (UI & world styles)
- js/ (modular engine & game logic)
- assets/ (kosong, Anda bisa menambahkan textures/sounds)
